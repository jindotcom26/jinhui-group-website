# 金滙控股集团官网

金滙控股集团的纯静态多页网站，通过 GitHub Pages 发布。

## 线上域名

- 主域名：`https://jinhui.group`
- `www.jinhui.group` 应通过 DNS CNAME 指向 `jindotcom26.github.io`

## 发布

网站由 GitHub Pages 从 `main` 分支根目录发布。提交并推送到 GitHub 后，通常数分钟内更新。

## 安全

- 网站不包含后端、数据库或环境变量。
- 不要提交客户资料、凭证、内部文件或未经脱敏的图片。
- 修改域名 DNS 时只替换网站的 A/CNAME 记录，保留 Google Workspace 的 MX/TXT 记录。
